# ESP32 桌邊藍牙控制器

ESP32-C3 核心板 + Display-Keypad 擴充板(0.96" 160×80 螢幕 + 五向鍵),橫向使用:**螢幕在左、按鍵在右**。
韌體是 MicroPython,手機端是 Android 配套 App(Kotlin),兩者用藍牙 BLE 溝通。

**目前版本:韌體 0.29.2 / App 1.14.1(versionCode 36)**

```
deskctl/
├─ firmware/   板子上的 MicroPython 程式 + font12.bin(繁中點陣字型, 15,192 字)
├─ android/    手機端 App 原始碼(Android Studio / GitHub Actions 皆可打包)
├─ tools/      upload.sh / upload.bat(上傳韌體)、make_font.py(重製字型)、build_mpy.py(選用)、sim/(桌面模擬與測試)
└─ .github/workflows/build-apk.yml   推上 GitHub 就自動打包 APK
```

## 1. 它能做什麼

| 功能 | 說明 |
|---|---|
| 首頁 | 時間日期(手機校時)、藍牙狀態、手機電量、正在播放的歌;首頁也能直接控音樂 |
| 音樂 | 播放/暫停、±5 秒精準跳轉、上下首、音量、隨機/循環、靜音;顯示歌名、進度、輸出裝置 |
| 碼表 | 背景持續計時、記圈 |
| 比分板 | MLB / NBA / CPBL / 足球即時比分,多個畫面(壘包、球數、得分、球員、球隊數據…) |
| 手機控制 | 方向鍵當手機的滾動/點擊/手勢遙控,可存多組模式 |
| 捷徑 | 手機設定好一串動作(開 App、點擊、播放…),控制器一鍵執行 |
| 手機訊息 | 轉發 LINE/簡訊等通知到控制器;手機端另有**訊息資料庫**(不用開原本的 App 就能先看) |
| 桌面小工具 | 開關、控制列、訊息、捷徑四種,桌面點一下啟動/停止連線 |
| 手機狀態 / 系統總覽 | 手機電量、網路、背景限制、記憶體;控制器自己的版本、記憶體、連線狀態 |
| 手機清理 | 結束背景 App、清快取、清最近使用 |
| 遊戲 | 貪吃蛇、1A2B、隨機取數、骰子猜大小 |

**為什麼需要手機 App?** 純 HID 藍牙(像藍牙鍵盤)只能「送按鍵」,讀不到手機現在播什麼、播到幾秒、電量與音量。要在螢幕顯示這些、做到精準跳轉,手機端必須有 App 讀取媒體工作階段並回報。通訊使用 Nordic UART 服務(BLE),每行一筆 JSON(見 [12.3](#123-通訊協定))。

## 2. 硬體與接腳

擴充板是**旋轉 180° 疊在核心板上**,擴充板第 n 腳接到核心板第 33−n 腳(電源腳 1/2/7/8/15/16 與 SPI 腳 SDA/SCK 都能對上,可交叉驗證):

| 功能 | 擴充板腳 | 核心板腳 | GPIO |
|---|---|---|---|
| **上**(橫放時) = 電路圖 UPKEY | 4 | 29 | 8 |
| **右** = 電路圖 LKEY | 3 | 30 | 9 (BOOT 鍵) |
| **中** = CENTER | 5 | 28 | 4 |
| **左** = 電路圖 DWKEY | 6 | 27 | 5 |
| **下** = 電路圖 RKEY | 23 | 10 | 13 |
| 螢幕 BL / CS / DC / RES | 9 / 10 / 11 / 12 | 24 / 23 / 22 / 21 | 11 / 7 / 6 / 10 |
| 螢幕 SDA(MOSI) / SCL(SCK) | 13 / 14 | 20 / 19 | 3 / 2 |

要改腳位只要改 `firmware/config.py`。

**注意**
- 板子橫放(按鍵在右)時,實體方向比電路圖上的名稱轉了 90°,上表是「橫放後的方向」。若仍不對,在 `config.py` 對調 `PIN_*` 數字即可;校正畫面最下面會顯示你按到哪個鍵。
- **開機/重啟的瞬間不要按住「右」鍵**(GPIO9 = BOOT,會進下載模式)。中央長按 5 秒重啟時放手即可。
- GPIO13 同時接板上 LED,若「右」鍵偶爾誤判,可改軟體消除。
- **背光無法控制(已實測)**:背光接在 GPIO11(ESP32-C3 的 VDD_SPI 腳),拉高拉低都沒有效果,所以背光一直是亮的。`config.py` 的 `BL_CONTROL` 預設 `False`:不做調光,設定裡也不顯示「背光亮度」「變暗時間」。閒置時仍有「時鐘待機」與「自動熄屏」(面板 Sleep,畫面全黑)。想真的省背光電只能改硬體:把 LCD_BL 線改接可用 GPIO(例如焊到 GPIO0),再改 `PIN_BL` 並設 `BL_CONTROL = True`。**不建議燒 eFuse**(不可逆,可能變磚)。

## 3. 燒錄與上傳韌體

需要一台電腦做一次。

1. 下載 MicroPython 的 **ESP32_GENERIC_C3** 韌體(micropython.org/download/ESP32_GENERIC_C3/),用 `esptool` 燒錄:
   ```
   esptool.py --chip esp32c3 --port COM5 erase_flash
   esptool.py --chip esp32c3 --port COM5 --baud 460800 write_flash --flash_mode dio 0 ESP32_GENERIC_C3-xxxx.bin
   ```
   **一定要加 `--flash_mode dio`**:這塊板子的 SPI Flash 在 QIO 模式會和 GPIO12/13 衝突,而「右」鍵就接在 GPIO13。(USB-C 接板上 CH343P 那顆;Windows 需要 CH343 驅動。)
2. 上傳程式,兩種方式擇一:
   - `pip install mpremote`,執行 `tools/upload.sh COM5`(Windows 用 `tools\upload.bat COM5`),會把 `firmware/` 全部傳上去並重啟。
   - 用 **Thonny**:選 MicroPython (ESP32) 直譯器,把 `firmware/` 裡**所有檔案**(含 `font12.bin`)上傳到板子根目錄,重新插電。
3. 第一次開機會出現**螢幕校正畫面**:上=轉方向、**右=換面板型號(偏移)**、下=反相、左=RGB/BGR 色序,調到「文字正、按鍵在右、R/G/B 色塊顏色對」後按中央儲存。之後可在 目錄→快捷設定→螢幕方向校正 重做。

**升級韌體**:只需覆蓋有變動的檔案(整包覆蓋也可以),設定檔 `settings.json` 不要刪,會保留設定。版本號在 `config.py`,畫面「系統總覽→運作」可確認有沒有上傳成功。

## 4. 手機 App 安裝與首次設定

### 打包

**方法 A:不用裝 Android Studio**
1. 把整個 `deskctl` 資料夾推到你自己的 GitHub repo(私人的也行)。**請確認 `android/app/debug.keystore` 有一起上傳**。
2. 到 repo 的 Actions → Build APK → Run workflow,完成後下載 artifact 裡的 `app-debug.apk`,傳到手機安裝。

**方法 B:** 用 Android Studio 開 `android/` 資料夾,Build → Build APK。

**簽章與覆蓋安裝**:專案內附固定的除錯簽章(`debug.keystore`),所以之後每次打包的 APK 都能**直接覆蓋安裝並保留設定**。若手機上裝的是更早、用別的簽章打包的版本,**第一次**會因為簽章不同而無法覆蓋,需先解除安裝一次(之後就不用了;解除安裝會清掉 App 內的設定、捷徑、追蹤清單)。

### App 的分頁(下方 5 個大分類,同類用上方分段按鈕切換)

| 分類 | 內容 |
|---|---|
| **主頁** | 大狀態卡(灰=已停止、橘=連線中、綠=已連線 + 連線時間)、**啟動/停止**、重新連線、手機訊息資料庫入口、初次設定提醒 |
| **比分** | 選聯盟(MLB / NBA / CPBL / 足球)與日期、追蹤比賽、籃球延遲播放設定 |
| **功能** ▸ 捷徑 | 建立/編輯/測試捷徑 |
| **功能** ▸ 手機控制 | 手機控制器的模式編輯(見 [第 7 節](#7-手機控制器)) |
| **功能** ▸ 助理 | **AI 助理**(Gemini):對話、查看目前設定與狀態、提議設定變更、給設定連結、上網查資料(見 [AI 助理](#ai-助理gemini)) |
| **功能** ▸ 按鍵 | 控制器**快捷鍵**(全域與各功能專區)與控制器設定(見 [自訂快捷鍵](#自訂快捷鍵手機設定板子執行)) |
| **狀態** ▸ 狀態 | 手機狀態(電量、網路、背景…)與控制器狀態(版本、記憶體…)、清理按鈕 |
| **狀態** ▸ 記錄 | 連線、斷線(含狀態碼)、指令與錯誤;可複製/分享/清除/只看異常,重開 App 還在 |
| **設定** | 初次設定、偏好、手機訊息、訊息資料庫、控制器目錄順序、控制器、關於。**除「初次設定」外各區預設收合,點標題展開** |

### 首次設定(到「設定」分頁依序按)

1. 授權藍牙與通知。
2. 開啟「通知存取」並勾選「桌邊控制器」(Android 讀取其他 App 歌名/進度的唯一合法管道)。Android 13+ 若灰色不能勾:按下方「允許受限設定」進 App 資訊 → 右上 ⋮ → 允許受限設定。
3. 把電池設定改成「不受限制」,避免系統在背景殺掉服務。
4. (選用)「顯示在其他 App 上層」與「無障礙服務」:捷徑與手機控制器需要,見第 8、7 節。

之後回「主頁」按**啟動**即可。板子要先通電;App 會自動搜尋 `DeskCtl` 並記住,之後斷線會自動重連,手機重開機也會自動啟動(啟動過一次後)。常駐通知上也有「重新連線」「停止」按鈕,不用開 App。連上後控制器右上角藍牙圖示變**綠色**,首頁時間會自動校準。

### 搜尋與省電設定

- **找不到控制器時**:每輪搜尋約 1 分鐘,休息 10 分鐘再試;連上後一直保持連線(「找不到時每 10 分鐘才搜尋一次」可關,關閉=持續搜尋)。按「重新連線」隨時可手動搜尋。
- **完全不搜尋時段**(例如 23:00~07:00):此時段斷線也不搜尋,時段結束自動恢復;手動「重新連線」可提前搜尋。
- **連線時保持 CPU 不休眠**(預設開):螢幕關閉時計時與藍牙不被凍結,代價是較耗電。

## 5. 控制器操作總表

手勢:**短按** / **雙擊** / **長按**(>0.6 秒) / **超長按**(5 秒)

### 全域
| 操作 | 功能 |
|---|---|
| 中央長按 | 開啟目錄(目錄中再長按 = 回原頁) |
| 中央連按 3 下 | **回首頁**(已在首頁則回到剛才的頁面,可來回切換;遊戲中無連按判定,請用中央長按進目錄) |
| 中央長按 5 秒 | **重啟整台裝置**(按住 1.8 秒後螢幕顯示倒數) |
| 方向鍵長按 5 秒 | **該頁重設 / 重新同步**(首頁、音樂=向手機重新要資料;碼表=歸零;遊戲=重新開始;比分板=重新同步) |
| 左 / 右 短按 | 非音樂頁:依「快捷清單」切換前/後一頁(比分板、手機控制頁除外,它們的左右鍵有自己的功能) |

### 目錄
上下選擇 · 中央進入 · **右鍵 = 加入/移出★快捷清單** · 左鍵返回。項目順序可由手機 App 設定。

### 狀態欄(右上角,由右至左)
時鐘(預設不顯示秒) · 藍牙(綠=已連線) · ▶ 手機正在播放音訊 · 碼表圖示(計時中) · 信封(有未讀訊息)。比分板與手機控制頁會在圖示左邊加一個標籤(比分板:資料幾秒前更新;手機控制:`R90` 之類的旋轉角度)。標題太長會自動截斷。

### 首頁
預設 12 小時制並顯示秒(首頁與狀態欄的秒數可分開設定)。顯示時間、日期、藍牙狀態、手機電量(含充電)、正在播放的歌。
**首頁也能控制音樂**:中央 播放/暫停 · 中央雙擊 靜音 · 上/下 音量(可按住) · 上雙擊 隨機 · 下雙擊 循環 · 左/右雙擊 上一首/下一首 · 左/右長按不放 連續倒轉/快轉。(左/右**短按**仍是快捷切換頁面,所以首頁沒有單擊 ±5 秒。)

### 桌面(桌邊擺放用)
目錄裡的「桌面」:整個螢幕自己畫(不顯示上方狀態列),適合立在桌上當小時鐘 + 音樂面板。
- **上列**:日期與星期(左);手機電量與充電、藍牙狀態、未讀訊息、碼表執行中圖示(右)。
- **中間**:大時鐘(冒號每秒閃一輪:前半秒亮、後半秒暗),右側小字上午/下午與秒數,最右側是**播放裝置圖示**(綠色耳機=藍牙耳機、藍色耳機=有線耳機、手機圖示=手機喇叭)與**音量百分比**(靜音時紅色喇叭叉)(是否顯示秒、12/24 小時沿用首頁設定,可在手機「按鍵」分頁「桌面」區修改)。
- **下方**:正在播放的**歌名**(太長會捲動)、**歌手**、暫停/播放圖示、進度條與 已播/總長(進度條右端會依時間文字寬度自動縮放,不會碰到數字);沒在播放時顯示連線狀態。調音量時會跳出音量提示。
- **按鍵與首頁相同**:中央播放/暫停、中央雙擊靜音、上下音量、長按左右快轉、左右雙擊上一首/下一首;左右單擊切換快捷頁。
- **待機**:閒置進入「低亮度/時鐘待機」時,若目前就在桌面或首頁不會被換頁(其他頁會自動切到首頁當時鐘)。想讓它成為常用畫面,可在手機「設定」的目錄順序把「桌面」排前面並加入快速切換(★)。

### 碼表
中央 開始/暫停 · 上 記圈 · 下 重設(需先暫停) · 下雙擊 隨時強制重設 · **上/下長按 = 捲動圈數清單**。背景持續計時,計時中所有頁面右上角都有碼表圖示。超過 1 小時改用 h:mm:ss 排版。

### 音樂
| 操作 | 功能 |
|---|---|
| 中央短按 | 播放 / 暫停 |
| 中央雙擊 | 靜音 / 取消靜音 |
| 右短按 / 左短按 | 快轉 +5 秒 / 倒轉 −5 秒 |
| 右雙擊 / 左雙擊 | 下一首 / 上一首 |
| 右 / 左 長按不放 | 連續跳轉 |
| 上 / 下 短按(可按住) | 音量 + / − 一格 |
| 上雙擊 | 隨機播放 開/關 |
| 下雙擊 | 循環模式:不循環 → 清單循環 → 單曲循環 |

螢幕顯示:歌名(太長會捲動)、歌手·專輯、進度條、目前/總時間、隨機/循環狀態、音量、輸出裝置圖示(綠=藍牙耳機、藍=有線、手機=手機喇叭)。跳轉秒數、音量步進可在快捷設定調整。

### 遊戲
清單上下選、中央開始;遊戲中**中央雙擊回清單**。
- 貪吃蛇:方向鍵轉彎,穿牆,中央暫停,越吃越快
- 1A2B:左右選位、上下**單按**改數字、中央送出;紀錄超過 5 筆時**上下長按**翻看舊紀錄
- 隨機取數:設定範圍(預設 000~999)與個數,最右格切換「重複/不重複」;中央抽,結果太多時上下捲動,中央再抽一次,雙擊回設定;設定會記住
- 骰子猜大小:上 押大(11–17)、下 押小(4–10)、左右調下注;豹子通殺

上下翻頁(25 頁,含按鍵位置圖解),涵蓋手勢、各功能頁操作、省電與連線。

時間制 12/24 · 首頁顯示秒 · 狀態欄顯示秒 · 閒置省電 · 低亮度/時鐘待機 · 自動熄屏 · 深度睡眠(實驗) · 新訊息喚醒螢幕 · 狀態欄訊息圖示 · 跳轉秒數 · 音量步進 · 藍牙診斷(中央歸零) · 重新連線藍牙 · 螢幕方向校正 · 還原所有設定

## 6. 比分板(MLB / NBA / CPBL / 足球)

### 設定與資料來源
- 手機 App「比分」分頁:選聯盟與日期(台灣時間) → 點「追蹤」加入(最多 8 場),可調整順序/移除。手機在背景抓資料傳給控制器的「比分板」頁。比賽清單與追蹤清單都顯示中文隊名。
- 資料來源:**MLB** = statsapi.mlb.com(官方);**NBA** = cdn.nba.com,失敗或季前賽改用 ESPN(賽程會合併兩邊,季前賽也找得到);**CPBL** = cpbl.com.tw 官網,無公開介面,屬**實驗性**,網站改版可能失效,失敗原因在「記錄」分頁(標籤 CPBL);**足球** = ESPN 公開介面(英超、西甲、德甲、義甲、法甲、歐冠、歐霸、美職、世界盃等 16 個聯賽,手機「比分」分頁選「足球」後點「聯賽」可複選要查哪些;預設英超+歐冠)。足球畫面:主畫面(比分、分鐘、射門/控球、黃紅牌數)→ 進球與紅黃牌時間線 → 球隊統計兩頁(控球/射門/射正/角球、犯規/越位/黃牌/紅牌);延長賽與PK大戰會顯示。欄位尚未用真實資料驗證,缺資料的頁面顯示「等待數據」。
- **隊名**:手機畫面一律「中文 英文 (代號)」並列;控制器下方一行依「隊名語言」(比分分頁的「隊名」卡片切換:中文優先 / 英文),沒有中文名的球隊自動用英文。中文來源:MLB/NBA 用代號對照、CPBL 本來就是中文、足球用 ESPN 英文全名對照。仍查不到的球隊,在追蹤清單按「改名」自己填中文(存在手機上,留空恢復內建)。
- **更新頻率**:控制器停在比分頁時,選中的 NBA 進行中比賽 4 秒、MLB 進行中比賽 5 秒、其他 8 秒;不在比分頁時有比賽進行中 30 秒、都沒進行中 3 分鐘。連續失敗會自動拉長間隔(沒網路或被限流時不會狂打)。MLB 即時細節只在比分頁開著、而且只抓正在看的那一場。

### 上方的更新秒數
比分頁右上固定顯示 `(:03)` = 手機 3 秒前確認過資料,`(01:)` = 1 分鐘前;**每次收到更新就歸零**,不分比賽狀態、不會因標題太長被省略。

### 籃球延遲播放(防劇透/計時穩定)
手機「比分」分頁的「籃球延遲播放」(預設 15 秒,可選 關閉/10/15/20/30):控制器正在看的 NBA 進行中比賽會**延後播出**,期間先收好幾筆資料。
- 計時器**不預測未來**:手機送出的每一筆都附上「下一筆真實資料的剩餘時間(`cn`)與相隔毫秒(`cd`)」,板子只在兩筆已知資料之間推進,到了 `cn` 就停住等下一筆;停表(暫停、罰球)的區段維持不動。
- **一秒一秒走**:計時在跑時顯示固定每秒減 1(最後一分鐘到 0.1 秒),不會因為資料忽快忽慢一次跳好幾秒;若顯示落後資料超過 5 秒才略微加速追上,資料說已停就很快收斂;顯示絕不比已知資料更前面。
- 剛選到比賽時先立刻顯示目前比分,計時器顯示「緩衝中」倒數,緩衝完從第一筆開始,順著之後收到的資料連續倒數。
- 只影響籃球且只影響控制器正在看的那一場;其他場與棒球維持即時。關閉延遲則回到推算模式(以最近一筆往下推)。
- 畫面比真實賽況晚「延遲秒數」;上方的 `(:xx)` 不含這個延遲。

### `+2/+3` 與最近得分
手機優先用逐球紀錄(NBA CDN 或 ESPN)判斷誰得分、幾分;抓不到就用前後兩次比分差推算。**板子自己也會比對前後兩筆比分**,所以任何資料來源都有效,並保持到下一次得分。限制:剛選到比賽、還沒看到任何一次得分之前沒有 `+N`(沒東西可比)。

## 7. 手機控制器

控制器目錄的「**手機控制**」頁 + 手機 App「**控制**」分頁。把方向鍵變成手機的遙控器。

- **上下左右鍵**:單擊 / 連按兩下 / 長按(不放會連續)都傳給手機,依目前「模式」執行。
- 動作類型:往某方向**滾動**一格 · **點擊/長按**指定位置 · **滑動** · 返回/桌面/多工/通知欄 · 音量 · 播放控制 · **開 App**(如相機) · 執行**捷徑** · **切換模式**。預設:上下左右=滾動,中央=點畫面中央。
- **中央**:單擊 = 手機定義的動作(預設點畫面中央);**兩下 = 四個方向的功能順時針轉 90°**(方便手機橫放,會記住);**三下 = 回首頁**;長按 = 目錄。
- 螢幕以十字圖顯示每個方向目前的功能,標題顯示模式名與第幾組(`瀏覽 1/2`),按鍵時該方向會閃一下。
- 可存最多 10 組模式;切換方式:把某個手勢設成「切換模式」(預設 左鍵連按兩下)。預設有「瀏覽」「影片」兩組。
- 沒設「連按兩下」的方向會用 fast 模式(單擊立即送出,不等 0.26 秒);手機會告知哪些方向有設兩下。
- 滾動/點擊/滑動/返回等需要**無障礙服務**(與捷徑共用);長按連續滾動時,上一筆手勢沒跑完會略過,避免堆積。
- 若你自訂過目錄順序,到手機 App 的目錄設定把「手機控制」加進去(新頁面第一次連線時會自動補進,你刻意隱藏過的不會被加回來)。

## 8. 捷徑、訊息、清理、狀態

### 捷徑(手機設定、板子上一鍵執行)
手機 App「捷徑」分頁新增捷徑,控制器目錄的「捷徑」頁會顯示同樣的名單,上下選、**中央執行**,手機依序做完並回報「完成 / 失敗」。手機上按「▶ 測試」可不用板子直接試跑,過程寫在「記錄」。

步驟類型:開啟 App · 開網址(可指定瀏覽器,如 Brave) · 等待幾秒 · 媒體鍵 · 點擊畫面位置 · 點擊含某文字的按鈕 · 按返回 · **重新整理目前頁面** · 喚醒螢幕 · **確保播放中**(取消靜音 → 送播放鍵 → 真實觸控點播放器,最多 3 輪,偵測到聲音就結束) · **點第一部影片**(搜尋結果頁找第一個大的可點項目,略過廣告/Shorts) · 結束背景 App + 清快取 · 清除最近使用。

內建範本:開啟 App 並自動播放 · 重新整理網頁 · 用瀏覽器開網址 · YouTube 搜尋並播放第一部影片 · 手機清理。

**點擊位置不用自己算座標**:編輯「點擊畫面」步驟時按「在畫面上選取」,App 退到背景,切到目標畫面,拖曳紅色準星到要點的位置按「確定」,就會填入橫%、縱%。

**需要的權限(設定分頁,皆為選用)**
- 「顯示在其他 App 上層」:Android 10+ 禁止背景直接開 App,有這個權限(或無障礙服務)才能從背景開啟。
- 「無障礙服務」:「點擊畫面 / 點擊文字 / 返回 / 手機控制器」需要。它不讀取也不上傳畫面內容。Chrome 系瀏覽器(Brave)要把服務關掉再開一次才會把網頁內容提供給它。Android 13+ 若灰色不能開:App 資訊 → ⋮ → 允許受限設定。

限制:沒有無障礙就點不到畫面;不同音樂/瀏覽器 App 對「播放鍵」「自動播放」的反應不一(瀏覽器可能擋自動播放);**捷徑需要手機螢幕已解鎖**。

### 手機訊息(通知轉發)
- 手機 App 把新通知(LINE、簡訊、Email…)轉發到控制器的「手機訊息」頁。**總覽**:上下選、中央看內容、**長按左=刪除此則、長按右=刪除全部**;**內容中**:上下捲動、**長按左=刪除此則、長按右=標記/解除標記**。
- **已標記(黃色方塊)的訊息不會被刪除**(全刪會跳過、手機端清掉通知也不會帶走、超過 12 則時也最後才丟),要刪必須先長按右解除標記。粉紅點=未讀。標記只存在記憶體,重開機會清空。
- 新訊息會跳提示、喚醒螢幕、狀態欄出現信封圖示(可在快捷設定關閉);在手機上把通知滑掉/已讀,控制器上也會跟著消失。
- 需要「通知存取」權限。手機 App「設定 → 手機訊息」要先按「選擇要轉發的 App」勾選(**只轉發有勾選的 App**),另可關閉轉發、**隱藏內容**(只顯示 App 名稱)。所有選 App 的清單都有搜尋欄。常駐通知、播放器、進度條、群組摘要與本 App 的通知不轉發。控制器只在記憶體保留最近 12 則。

### 桌面小工具
在手機桌面長按 → 小工具 → 找「桌邊控制器」,共四種(可各放多個):

| 小工具 | 大小 | 功能 |

| 桌邊控制器 開關 | 1×1 | **點一下啟動連線(搜尋並連上控制器),再點一下停止**;灰=已停止、橘=連線中/休息中、綠=已連線 |
| 桌邊控制器 控制列 | 4×1 | 啟動/停止 · 重新連線 · 訊息(顯示未讀數,點開訊息資料庫) · 清理控制器記憶體 |
| 手機訊息 | 2×2 | 最新 4 則訊息(● = 未讀),點一下開啟訊息資料庫 |
| 桌邊控制器 捷徑 | 4×1 | 前四個捷徑一鍵執行(需已連線) |

- 連線狀態改變、新訊息、已讀時,小工具會自動更新。
- 第一次使用前請先開過 App 完成藍牙授權(小工具沒有授權時會帶你回 App)。
- 長按 App 圖示還有「訊息」捷徑,可拖到桌面直接開訊息資料庫。
- 想再加小工具:見 `Widgets.kt` 開頭的說明(寫一個 `BaseWidget` 子類別 + layout + `xml/*_info.xml`,在 Manifest 登記,加進 `providers` 與 `build()`)。

### 手機訊息資料庫
手機把收到的通知存在**手機本機**(SQLite,不上傳),不必連著控制器、也不必啟動連線,只要「通知存取」已開啟就會收錄,你可以直接在 App 內先看內容,不用打開 LINE 等原本的 App。

**三層結構**
1. **App 清單**:每個 App 一張卡片(未讀數、最後時間),點進去看該 App。
2. **對話清單**:社群/通訊 App(LINE、Messenger、WhatsApp、Telegram、簡訊、Instagram…,以及通知本身標示為「訊息」的 App)會**依聯絡人或群組分成不同的對話**,每個對話顯示最後一則預覽與未讀數;其他 App(信箱、系統通知…)直接依時間列出。上方按鈕可把某個 App 的「依對話分組」切成 自動 / 開 / 關。
3. **訊息串**:點進對話看這個人(或群組)的所有紀錄,**由舊到新、最新在底部**。分界很清楚:
   - **日期標題**(今天 / 昨天 / 2026/10/15 星期四)分隔不同天;
   - 同一天內相隔超過 30 分鐘,會畫一條「間隔 2 小時 10 分後」的分隔線;
   - 開啟對話時,第一則未讀訊息前會有紅色「**以下為新訊息**」分隔線,開啟後該對話標為已讀;
   - 訊息太多時上方有「載入更早的訊息」。

**其他功能**
- 入口:App 主頁「手機訊息資料庫」按鈕、設定分頁、桌面小工具、長按 App 圖示的「訊息」。
- 搜尋(App 名稱/標題/內容)跨所有對話,點一則結果會直接跳到那個對話。右上「全部已讀」「刪除」會依你所在的層級作用在 全部 / 該 App / 該對話。
- 長按:App 卡片=開啟該 App;對話卡片=刪除該對話;訊息=複製 / 開啟該 App / 刪除這則。
- 在手機上把通知滑掉或已讀時,資料庫裡該則也會自動**標為已讀**(不會刪除)。
- 收錄哪些 App:與「轉發到控制器」共用同一份 App 清單;設定分頁可另開「收錄所有 App」。常駐、進度、播放器、群組摘要與本 App 的通知不收。「隱藏內容」只影響轉發到控制器,不影響資料庫。
- **預設永遠保留,只有你自己刪才會刪**(刪除都會再確認一次)。設定分頁「自動刪除舊訊息」可改成 30/90/180/365 天(預設「永不」)。
- 限制:只能存「通知裡有的文字」(長訊息可能被 App 截短);App 沒有發通知就收不到;對話是用通知標題(聯絡人/群組名)區分的,若 App 的通知標題不是對話名稱,可能分得不理想,這時把該 App 的「依對話分組」關掉即可。升級前已收錄的舊訊息會保留,並用標題當對話名稱。

### 自訂快捷鍵(手機設定、板子執行)
手機 App 的「按鍵」分頁:上方選**區域**,每個區域有自己的快捷鍵清單與該區的控制器設定。

| 區域 | 快捷鍵範圍 | 同區可改的控制器設定 |
|---|---|---|
| 全域 | 任何頁面 | 無 |
| 首頁 | 只在首頁 | 時間制、首頁顯示秒、狀態欄顯示秒 |
| 音樂 | 只在音樂頁 | 快轉秒數、音量步進 |
| 碼表 / 比分板 / 捷徑 / 手機控制 | 只在該頁 | 無 |
| 訊息 | 只在訊息頁 | 新訊息喚醒螢幕、狀態欄訊息圖示 |
| 省電與系統 | 無快捷鍵 | 閒置省電、低亮度/時鐘待機、自動熄屏、深度睡眠(背光可調時另有變暗時間/亮度);「清除全部快捷鍵」 |

- **一筆快捷鍵** = 按鍵(左 上 中 下 右)+ 手勢(**雙擊 / 三連擊 / 長按**)+ 動作。中鍵只能綁雙擊(三連擊=回首頁、長按=目錄、超長按=重開機固定給系統)。上限 24 個。
- **動作**:切換到頁面、回上一頁、回首頁、開關目錄、快速切換上/下一個、立即熄屏(按任一鍵喚醒)、播放/暫停、上/下一首、靜音、音量加/減、快轉/倒轉、執行手機捷徑、清理控制器記憶體。
- **生效順序**:專區的快捷鍵永遠先於該頁原本的功能;全域快捷鍵預設也「優先於頁面」(可取消勾選,取消後只在頁面沒用到該手勢時才生效)。編輯畫面會列出這個手勢在哪些頁面原本有功能、會被蓋掉或不生效。
- **三連擊的代價**:有綁三連擊的方向鍵,雙擊要多等約 0.26 秒才確認(遊戲頁不受影響)。
- **同步**:快捷鍵存在手機與控制器兩邊,離線時控制器照常使用;手機沒改過時以控制器上的為準(換手機不會清掉)。控制器設定與控制器上的「快捷設定」頁雙向同步(連線時才能在手機顯示與修改)。

### AI 助理(Gemini)
「功能 ▸ 助理」:用你自己的 **Gemini API 金鑰**(到 aistudio.google.com/apikey 免費申請;金鑰只存在手機、只送給 Google)和 AI 對話。

- **能做什麼**:問「目前設定是什麼 / 控制器狀態如何 / 為什麼連不上」(助理會先讀 App 與控制器的真實狀態再回答);說「把左鍵雙擊設成上一首」「這支球隊中文怎麼叫」(助理提議變更);要它給設定畫面的**連結按鈕**(按鍵、捷徑、比分、通知存取權、電池最佳化、藍牙設定、App 資訊…);**上網搜尋**查不到的資料(例如球隊的台灣譯名)。
- **安全**:助理只能「提議」變更(控制器設定、快捷鍵、自訂隊名、隊名語言),畫面上會出現橘色卡片寫清楚改什麼,**按「套用」才生效**,按「略過」就不改。網路搜尋回來的內容不會直接改任何設定。
- **隱私**:只送出你的提問、目前設定與狀態(連線、版本、記憶體、設定值、快捷鍵、追蹤的比賽與隊名、捷徑名稱);**不會送通知或訊息內容**。對話只存在記憶體,離開 App 就忘記(可按「清除對話」)。

- **限制**:Gemini 介面的細節(工具呼叫、`google_search` 搜尋工具、模型名稱)尚未用真實金鑰驗證;若出現「請求被拒」「找不到模型」,先檢查金鑰與模型名稱,再把「記錄」分頁(標籤 AI)的內容貼給開發者。搜尋與一般對話分開呼叫(搜尋模式不能同時用工具呼叫)。

### 手機清理
- 控制器「手機狀態」頁:**中央 = 結束背景 App + 清本 App 快取**;**中央雙擊 = 再加清除最近使用清單**。結果會跳提示(例如「完成 清理 釋放約 300MB」)。手機 App「狀態」分頁、捷徑也有同樣功能。
- 做的事:① 結束背景 App(自動保護:本 App、有媒體工作階段的 App、輸入法、桌面,以及你在「選擇清理時要保護的 App」勾的);② 清除本 App 快取;③ 用無障礙服務開啟最近工作並點「全部關閉」。
- **做不到的**:Android 不允許第三方 App 清除「別的 App 的快取」,也不能真正「釋放系統快取」;系統本來就會自己回收記憶體,結束背景 App 的效果是暫時的,重開的 App 反而更慢更耗電。建議只在手機卡頓時用。

### 手機狀態、系統總覽、目錄順序
- **控制器「手機狀態」頁**(4 個子頁,上下切換;綠=正常 黃=注意 紅=有問題 灰=資料過期):電源(電量條、充電方式、溫度/電壓)、連線(網路、Wi-Fi 訊號、手機藍牙、螢幕、與控制器連線)、背景(「背景運作正常/需留意/可能被限制」+ 省電模式、Doze、背景限制)、資源(RAM、App 記憶體/快取、儲存剩餘)。手機每 10 秒回報;快捷設定的「重新同步」可立即要求重送。
- **控制器「系統總覽」**(不用開手機 App,每秒更新,上下切 4 頁):**總覽**(左手機/右開發板重點)、**運作**(韌體版本、已運作、目前頁面、重啟原因)、**記憶體**(已用%、剩餘、總量、頁面數、歷史最低,**中央 = 清理記憶體**;沒有趨勢圖,只顯示即時數字以節省記憶體)、**連線**(藍牙狀態、連線/斷線次數、上次連線時長、手機資料多久前)。晶片溫度在部分 MicroPython 版本沒有則顯示 --。
- **手機 App「狀態」分頁**:手機數據 + 控制器版本、已運作時間、目前頁面、記憶體、藍牙連線/斷線次數,以及「**清理控制器記憶體**」按鈕。
- **目錄順序**:手機 App「設定 → 控制器目錄順序」可上下移動、隱藏頁面、☆/★ 設定左右鍵快速切換;按「儲存並送出」,連線時自動送到控制器並存起來(「首頁」固定第一個、「設定」一定保留)。

### 背景運作(手機放一旁、App 沒開)
- 連線由前景服務(通知列常駐)負責,**不需要打開 App 畫面**;滑掉 App 也不影響,只有按「停止」或系統強制結束才會中斷。
- 音樂控制、電量、時間、狀態回報、比分在螢幕關閉/上鎖時都能運作;**捷徑與手機控制器需要螢幕已解鎖**(上鎖時只能喚醒螢幕)。
- 各家系統的省電機制不同(Samsung 的「休眠中的 App」、Brave 被系統凍結等),請在設定分頁完成「允許背景執行」,並把本 App 從休眠清單移除。

## 9. 省電、記憶體與穩定性

### 省電(閒置時自動)
| 閒置時間 | 狀態 |
|---|---|
| 未達「低亮度/時鐘待機」時間(預設 10 分鐘) | 正常 |
| 超過該時間 | **沒播歌時自動切到首頁當大時鐘**,CPU 放慢;按鍵後回到原頁(遊戲中不換頁) |
| 「自動熄屏」時間到(預設永不;可選 30 秒~2 小時) | 面板進入 Sleep,畫面全黑 |

低亮度/熄屏時第一下按鍵只負責喚醒;手機開始播放或來新訊息也會喚醒。「閒置省電」可關閉。**深度睡眠(實驗,預設關)**:主迴圈改用 `machine.lightsleep`,更省電,但可能影響藍牙連線與 USB 序列埠(Thonny 會斷線),連線變不穩請關掉。

### 記憶體(ESP32-C3 只有約 100 KB 可用)
已做的設計:
- **頁面與程式碼按需載入**:首頁/碼表/音樂常駐,其他頁面進入才載入、離開就卸載;比分頁再拆成多個小檔案(核心、共用畫法、棒球、即時/戰績、得分/星、籃球、籃球數據),只載入當前畫面需要的。
- 控制器只保留「正在看的那一場」的完整比分資料,其他場縮成精簡版;中文隊名由手機組好才送過來;藍牙接收就地處理、不產生大量暫時垃圾;捲動文字共用同一塊緩衝區。
- **清理記憶體**:「系統總覽 → 記憶體」中央、手機 App「狀態」分頁按鈕,或捷徑,會卸載不在用的頁面、重置最低值、做兩次垃圾回收,並回報釋放量。

### 發生 MemoryError 時(綠底白字畫面)
舊版 10 秒內連續 8 次就重開機。現在改為**逐級自救**,30 秒內:第 1 次整理並卸載其他頁面 → 第 2 次丟掉本頁暫存與收到一半的訊息 → 第 3 次回首頁 → 第 6 次還救不回來才重啟(畫面只顯示「記憶體不足,自動重新啟動中」)。
其他保護:
- 單則格式怪異的手機訊息只會被丟掉(序列埠印 `bad msg`),不會讓整台重開;
- 某一頁的畫面程式出錯只在該頁顯示「畫面錯誤, 見 err.log」,不重開機;
- 超過 6000 位元組仍沒有換行的壞資料自動丟棄;
- **致命錯誤與畫面錯誤會寫進板子根目錄的 `err.log`**(Thonny 檔案面板可直接開啟,只保留最新一筆),含錯誤行、當時剩餘記憶體與所在頁面。**回報問題時請貼這個檔案。**

### 設定檔安全
設定先寫暫存檔再改名,寫到一半斷電不會弄壞設定;主檔壞掉時會嘗試從暫存檔救回。

### 選用:改用 .mpy
`.mpy` 是預先編譯的位元碼,載入頁面時的**暫時記憶體尖峰**大幅降低(最容易 MemoryError 的時刻),常駐用量只小幅減少。目前預設仍使用 `.py`(不影響運作),需要時:
1. 板子上 `import sys; print(sys.implementation)` 記下版本。
2. 電腦 `pip install mpy-cross==<相同的 MicroPython 版本>`,執行 `python tools/build_mpy.py` 產生 `firmware_mpy/`。
3. Thonny 先刪掉板子上要換成 .mpy 的同名 `.py`(**`.py` 與 `.mpy` 並存時優先載入 `.py`**),再上傳 `firmware_mpy/` 內容(`boot.py/main.py/config.py` 維持 `.py`)。
4. 之後要修改韌體:改 `firmware/*.py` → 重新 build → 重新上傳。

## 10. 疑難排解

| 現象 | 處理 |
|---|---|
| 畫面全黑 | 到校正畫面試「上」換方向、「下」反相;確認供電 |
| 畫面鏡像/顛倒 | 目錄→快捷設定→螢幕方向校正,按「上」直到正確 |
| 紅藍顏色反了 | 校正畫面按「左」切換 RGB/BGR |
| 畫面歪斜/偏移/邊緣雜點 | 校正畫面按「右」切換面板型號(偏移規格) |
| 想重新校正 | **開機(插上電)時按住中央**,畫面左上會顯示版本號 |
| 已存過設定,進不了校正畫面 | `mpremote fs rm :settings.json` 後重啟,或在 Thonny 刪掉 `settings.json` |
| 綠底白字錯誤畫面 | 見 [第 9 節](#發生-memoryerror-時綠底白字畫面);打開 `err.log` 貼給開發者 |
| 圖示一直是灰色 | 手機 App 沒啟動 / 藍牙沒開 / 板子沒通電;黃色 = 已連上但 App 沒回應(重新按啟動) |
| 藍牙連一下斷一下 | 看手機「記錄」分頁(斷線代碼 8=訊號逾時、19=裝置端斷開、133=連線失敗);板子 快捷設定→藍牙診斷 顯示連線/斷線次數 |
| 手機找不到控制器 | 可能在「完全不搜尋時段」或 10 分鐘休息中:按主頁「重新連線」立即搜尋 |
| 沒有歌名 | 沒開「通知存取」,或沒有任何音樂 App 在播放 |
| 比分板「等待手機傳送比分」 | 手機 App 沒啟動/沒追蹤比賽/手機沒網路;看「記錄」分頁 SCORE 標籤 |
| 比分板沒有 `+2/+3` | 剛選到比賽、還沒看到得分變動前不會有;之後會保持到下一次得分 |
| 計時有點延遲 | 籃球延遲播放開著時畫面本來就晚幾秒;要即時可到「比分」分頁選「關閉」 |
| 歌名捲太快/太慢 | `config.py` 的 `MARQUEE_MS_PER_PX`(預設 50,越大越慢)、`MARQUEE_HOLD_MS`、`MARQUEE_GAP_PX` |
| 右鍵不靈 | GPIO13 與 LED 共用,請回報 |
| 桌面小工具點了沒反應 | 先開一次 App 完成藍牙授權;部分手機(Samsung、小米等)要把本 App 的電池設定改為「不受限制」;小工具顯示的狀態是最後一次更新時的狀態,重新放一個小工具可強制刷新 |
| 訊息資料庫是空的 | 確認「通知存取」已開、已選擇要收錄的 App(或開「收錄所有 App」),且「收錄通知到訊息資料庫」是開的;只收開啟之後收到的通知 |
| App 無法覆蓋安裝 | 簽章不同(舊版用別的金鑰打包),解除安裝一次後再裝;之後有固定簽章就能覆蓋 |

## 11. 已知限制(請先知道)

- **開發者無法在實體板子與手機上測試。** 韌體的畫面排版、手勢、頁面邏輯與藍牙封包處理都在桌面模擬器驗證過(`tools/sim/`),但 ST7735 的顯示方向/色序、GPIO13 與 LED 共用、記憶體在真實板子上的碎片情形、Android App 的實機行為,都依賴你實測回報。
- **資料來源欄位未全部對真實資料驗證**:NBA 逐球紀錄與球隊/球員數據(官方 CDN 與 ESPN summary)、CPBL 官網格式、MLB 5 秒更新對流量的影響。若某頁一直顯示「等待數據」,請把「記錄」分頁內容貼給開發者。
- 隨機/循環模式是否生效取決於音樂 App 是否開放(Spotify、YouTube Music 可能忽略);沒有媒體工作階段時,播放/下一首改送系統媒體鍵。
- 手機端同時只控制一個音樂 App:誰開始播放就切過去;都沒在播時控制最後播放過的。Brave/Chrome 網頁影片要有媒體通知才抓得到。
- 連線**沒有配對密碼**,範圍內的其他 BLE 裝置理論上也能連上;只連一台時別人連不進來。
- 捷徑與手機控制器需要手機已解鎖與無障礙服務;滾動手感因 App 而異。
- 板子重開機會清空:訊息、標記、最近得分(`+N`)、比分資料(手機會重送)。

## 12. 開發者:擴充、協定、測試

### 12.1 新增功能區/遊戲(韌體)
1. 在 `firmware/` 新增 `g_xxx.py`,寫一個繼承 `app.Page` 的類別(可參考 `g_dice.py`,約 100 行)。可覆寫 `enter/leave/on_key/tick/draw/get_title/get_tag/trim`(`trim` 在記憶體吃緊時被呼叫,用來丟掉可重建的東西)。
2. 在 `firmware/registry.py` 的 `PAGES` 加一行 `("id", "名稱", "g_xxx", "類別名", "game")`(群組 `main` 出現在目錄,`game` 出現在遊戲清單)。
3. 用 `tools/upload.sh` 或 Thonny 上傳。

### 12.2 新增手機端功能(模組化)
手機端每一塊功能都是一個 `Feature` 模組(`android/app/src/main/java/tw/deskctl/`),例如 `TimeFeature`、`BatteryFeature`、`MediaFeature`、`ScoreFeature`、`PadFeature`。`BridgeService` 只負責連線與收發。
1. 新增 `XxxFeature.kt`,繼承 `Feature(host)`,覆寫需要的:`start()/stop()`、`onReady()`(連線完成時送出完整狀態)、`onTick(n)`(每秒)、`onCommand(c, o)`(認領控制器傳來的 `{"c":"..."}`,處理了回傳 true)、`info()`。送資料用 `host.send(JSONObject().put("k","xxx")...)`,內容沒變就不重送用 `host.sendIfChanged`。
2. 在 `Features.kt` 的 `registry` 加一行 `FeatureEntry("xxx", "名稱") { h -> XxxFeature(h) }`。
3. 韌體端:`firmware/state.py` 的 `apply()` 加 `k == "xxx"` 處理;頁面用 `app.link.send({"c":"..."})` 發指令。
4. 要加「設定」:`Prefs.kt` 加 getter/setter,再到 `MainActivity.buildSettings()` 加開關。要記錄就用 `AppLog.i/w/e("標籤", "訊息")`,會自動出現在「記錄」分頁。
5. 新增捷徑步驟類型:在 `ShortcutFeature.step()` 加分支,並在 `ShortcutsPage` 的選單加一項。

撰寫 Kotlin 時的坑:KDoc 註解裡的 `[` 會被當成連結導致編譯失敗;新檔案要記得一起 commit。

**板子→手機(`c`)**
`pp` `next` `prev` `mute` `sync` `pong` · `seek {"d":±毫秒}` · `vol {"d":±格}` · `shuffle {"v":0/1}` · `repeat {"v":0/1/2}` · `run {"i":編號}` · `clean` / `clean2` · `stat {ver,up,mf,ma,pg,cn,dc,lu}`(每 10 秒) · `pages {"l":[[id,名稱]…]}` · `layout {"m":[…],"r":[…]}` · `sc {"on":1|0,"sel":欄位}`(比分頁是否開著與正在看哪場) · `pad {"d":0上/1右/2下/3左/4中央,"e":"c|d|l|h"}`(c 單擊 d 兩下 l 長按開始 h 長按重複;方向已扣除旋轉)· `memclean {"f","b","a"}` · `cfg {"d":{設定…},"hk":[…],"bl":0/1}`(連線與設定被修改後回報)

### 12.4 測試(桌面模擬,免實機)
需要 Python 3 與 `numpy`、`Pillow`(畫面截圖用)。在 `tools/sim/` 執行:
- `python3 test_all.py` — 手勢引擎 + 各頁面行為(比分、手機控制、記憶體自救…),結尾應為 `0 failures`
- `python3 test_layout.py` — 逐頁畫面排版(文字超出/重疊)檢查,應為 `0 layout issues`
- `python3 test_ble.py` — BLE 封包切割與重組、斷線重連
- `python3 test_upy_compat.py` — 檢查有沒有 MicroPython 不支援的寫法(如對 bytearray 切片刪除),應為 `0 compat issues`

注意:模擬器是 CPython,**無法重現 MicroPython 的記憶體限制與部分語法差異**,所以上傳前請同時跑 `test_upy_compat.py`。
